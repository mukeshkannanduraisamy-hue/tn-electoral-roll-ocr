# ---------------------------------------------------------------------------
# Everything the API needs EXCEPT the deep-learning framework.
#
# Split out because paddlepaddle and paddlepaddle-gpu are separate
# distributions that install into the same `paddle` namespace. Installing both
# leaves whichever landed last in charge, so a GPU image cannot simply add the
# CUDA wheel on top of `requirements.txt` -- it has to never install the CPU
# one. Hence: this file holds the shared half, and the two thin files beside it
# each add exactly one framework.
#
#     requirements.txt      -> this + paddlepaddle       (CPU, the default)
#     requirements-gpu.txt  -> this + paddlepaddle-gpu   (CUDA 12.6)
#
# Install `requirements.txt` unless you are building the GPU image; nothing
# else changed when this split happened.
#
# NOTE: cv2 is deliberately absent. paddleocr depends on
# `opencv-contrib-python`; adding `opencv-python(-headless)` alongside it
# installs a second package into the same `cv2` namespace and whichever lands
# last wins. Let paddleocr own it.
# ---------------------------------------------------------------------------
